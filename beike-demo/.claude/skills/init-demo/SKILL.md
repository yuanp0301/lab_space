# 备课Demo - Master Prompt 设计方案

## 一、项目背景与目标

### 1.1 业务背景

通过这个demo，老师能直观感受产品体验，反馈产品设计缺陷，帮助产品迭代升级。

**市场痛点**：

- 现有教学资源90%为"知识堆砌式"，缺乏系统化课程设计
- 老师备课需求从"完成任务"升级为"展示专业能力"
- 缺乏"为何这样设计"、"知识应用如何搭桥"的内核思路

**产品核心价值**：

- 提供"框架+内容"的系统化课程设计模版（不是空框架，而是完整填充的可用模版）
- 提供系统化全课知识点体系 + 规格化多媒体素材体系
- AI辅助：素材智能匹配 + 设计评估优化

### 1.2 Demo定位

**完整功能demo**，基于《秋天的怀念》课例：

- **展示创新亮点**：系统化课程设计模版（双线脉络、情境任务式、分组探究等教学模式）
- **体验AI辅助**：智能素材匹配、设计评估优化、作业生成
- **用户操作流程**：浏览完整课程设计 → 选择环节深入调整 → AI辅助创作 → 保存成果

## 二、功能模块设计（按优先级）

### 2.1 教学解读模块

**功能**：展示教学解读与定位的完整内容
**数据源**：`data/busi/3. 第一部分：教学解读与定位.md`
**交互**：只读展示，用户可查看但不可编辑
**内容包括**：

- 备课起点的思考（想什么、做什么、找什么、记录产出）
- 文本核心价值分析
- 学情分析建议
- 教学难点预判

### 2.2 课程设计模块 ⭐核心模块

**功能**：展示和编辑情境任务式课程设计
**数据源**：

- 初始模版：`data/busi/7.2 《秋天的怀念》情境任务式课程设计（完整版）.md`
- 用户调整后保存到：`data/users/{username}/课程设计.json`

**视图切换**：

- 表格式：类似Excel，清晰展示各项内容
- 卡片式：每个环节一张卡片
- 时间轴式：按教学流程顺序呈现
- 用户可自由切换

**内容结构**：

- 两课时完整设计
- 每个环节包含：主问题、子问题链、教学活动、知识点、预期成果、验证点

**AI辅助功能**：

1. **嵌入式AI按钮**：每个环节旁边有"AI优化"按钮，点击弹出AI对话窗口
2. **素材推荐**：选中某个环节，点击"推荐素材"，AI从素材库推荐合适素材
3. **设计评估**：完成设计后，点击"AI评估"，AI分析整体设计并给出优化建议

**编辑能力**：

- 可修改问题、活动、知识点
- 可添加/删除环节
- 可拖拽调整顺序
- 修改后模块间双向联动更新

### 2.3 课件生成模块 ⭐核心模块

**功能**：两种方式生成课件
**数据源**：

- 设计思路：`data/busi/6. 《秋天的怀念》课件设计思路.md`
- 用户生成后保存到：`data/users/{username}/课件内容.json`

**方式一：基于模版生成**

- 选择课件风格模板（提供2-3种深蓝色清冷风格模版）
- 基于课程设计内容，一键生成35页课件
- 自动匹配素材

**方式二：逐页生成/编辑**

- 查看每一页课件（35页完整结构）
- 逐页调整内容、替换素材
- 添加/删除/调整页面顺序

**输出形式**：

- PPT样式的HTML网页课件（类似reveal.js）
- 支持在线预览
- 支持翻页、动画效果

**AI辅助功能**：

- 每页课件都有"AI优化"按钮，可调整排版、文案、素材搭配
- "素材推荐"功能，根据页面内容推荐合适素材

### 2.4 知识点体系模块

**功能**：可随时唤起的全课知识点系统
**数据源**：`data/busi/4. 《秋天的怀念》全课知识点体系完整讲解.md`

**展示形式**：

- **默认**：树状结构（可展开/收起）
  - 一级分类：字音字形、词语释义、文学常识、文本鉴赏、情节分析等
  - 二级内容：具体知识点详情
- **搜索**：顶部搜索框，输入关键词快速定位知识点

**交互**：

- 只读展示
- 支持知识点复制
- 点击知识点，可以看到该知识点在课程设计中的应用位置

### 2.5 素材库模块

**功能**：规格化的多媒体素材体系
**数据源**：

- 素材清单：`data/busi/5. 《秋天的怀念》素材清单.md`
- 实际文件：`data/resource/pic/`、`data/resource/audio/`、`data/resource/video/`、`data/resource/file/`

**素材分类**（44类+）：

- **图片类**：作者肖像、母亲形象、场景还原、意象象征、图表图示等
- **音频类**：环境音效、配乐、朗读
- **视频类**：意境短片、微课解析
- **交互素材**：预习工具、细节分析工具、主题升华工具

**展示方式**：

- **画廊式浏览**：独立的素材库页面，分类展示所有素材
- **预览功能**：点击素材可放大预览（图片）、播放（音频/视频）
- **详细信息**：显示素材的风格、规格、适用教学环节

**使用方式**：

- 在素材库中点击"添加到课程/课件"
- 在课程设计/课件设计中使用"搜索+推荐"功能调用素材

**AI辅助**：

- 输入教学环节描述，AI推荐合适素材
- AI分析素材使用合理性

### 2.6 作业设计模块

**功能**：AI生成分层作业
**参考数据**：`data/busi/9. 《秋天的怀念》分层作业.md`
**保存到**：`data/users/{username}/作业设计.json`

**生成方式**：

- 基于用户的课程设计内容
- 点击"生成作业"按钮
- AI生成三层作业：基础练习、能力提升、创新应用

**编辑能力**：

- 可修改题目和答案
- 可添加/删除题目
- 可调整难度分层

## 四、技术实现规格

### 4.1 技术栈

- **前端框架**：Vue 3 + TypeScript
- **UI组件库**：Element Plus（深色主题定制）
- **路由**：Vue Router
- **状态管理**：Pinia
- **HTTP请求**：Axios
- **Markdown渲染**：markdown-it
- **课件展示**：reveal.js
- **构建工具**：Vite

### 4.2 AI集成

**API配置**：

- 使用Claude API
- API Key配置文件：`config/api.json`

```json
{
  "claude_api_key": "your_api_key",
  "claude_api_url": "https://api.anthropic.com/v1/messages",
  "model": "claude-3-5-sonnet-20241022"
}
```

**AI System Prompt**：

```
你是一位资深的语文教学专家，帮助老师设计高质量的课程。

你的专长包括：
- 分析教学内容，提炼核心价值
- 设计情境任务式、分组探究式等创新教学模式
- 推荐合适的教学素材
- 评估课程设计的有效性，提供优化建议
- 生成分层作业

请始终：
- 遵循新课标要求和核心素养导向
- 以学生为中心设计教学活动
- 提供具体、可操作的建议
- 保持专业、友好的沟通风格
```

**AI调用场景**：

1. **素材智能匹配**
   - 用户输入：教学环节描述
   - Context：素材清单（`data/busi/5`）
   - 输出：推荐3-5个合适素材及理由

2. **设计评估优化**
   - 用户输入：当前课程设计内容
   - Context：教学理论（`data/busi/3`）
   - 输出：评估报告（优点、问题、改进建议）

3. **作业生成**
   - 用户输入：课程设计内容
   - Context：参考作业（`data/busi/9`）
   - 输出：三层分层作业（基础、能力、创新）

4. **随时对话**
   - 用户可随时唤起AI助手
   - Context：当前页面内容+用户操作历史
   - 输出：针对性回答和建议

### 4.4 模块联动机制

**双向联动关系**：

- 课程设计 ↔ 课件生成：课程设计调整后，课件内容同步更新；课件调整后，可回溯到课程设计
- 课程设计 ↔ 作业设计：课程设计知识点变化，作业重新生成
- 素材库 → 课程设计/课件生成：素材添加后自动更新到对应位置

**实现方式**：

- 使用Pinia全局状态管理
- 各模块订阅相关state变化
- 变化时触发自动更新或提示用户

## 五、关键交互流程

### 5.1 用户首次进入

1. 显示欢迎页面（介绍demo核心能力）
2. 点击"开始体验"进入主界面
3. 默认加载"课程设计"模块
4. 右下角有"新手引导"按钮

### 5.2 课程设计调整流程

1. 用户浏览课程设计内容（默认表格视图）
2. 切换视图方式（表格/卡片/时间轴）
3. 选中某个环节，点击"编辑"
4. 弹出编辑对话框，修改内容
5. 点击"AI优化"，AI提供建议
6. 点击"推荐素材"，查看并选择素材
7. 保存修改
8. 系统提示：课件内容将同步更新

### 5.3 课件生成流程

**方式一：基于模版生成**

1. 进入"课件生成"模块
2. 点击"基于模版生成"
3. 选择模版风格（展示2-3个预览）
4. 点击"生成"
5. AI处理中（显示进度）
6. 生成完成，显示35页课件预览
7. 用户可逐页查看、编辑

**方式二：逐页设计**

1. 进入"课件生成"模块
2. 点击"逐页设计"
3. 左侧显示35页课件大纲（缩略图）
4. 点击某一页，右侧显示详细内容
5. 编辑内容、调整素材
6. 点击"AI优化"改善排版
7. 保存修改

### 5.4 素材智能匹配流程

1. 用户在课程设计或课件设计中
2. 点击"推荐素材"按钮
3. 弹出AI对话窗口
4. AI分析当前环节内容
5. 显示推荐的3-5个素材（带缩略图和理由）
6. 用户点击"使用"，素材添加到内容中
7. 用户也可以"打开素材库"手动选择

### 5.5 数据保存流程

1. 用户完成调整后，点击"保存"按钮
2. 弹出对话框："请输入用户名"
3. 用户输入用户名（如"张老师"）
4. 系统检查`data/users/张老师/`是否存在
5. 不存在则创建文件夹
6. 保存对应的JSON文件
7. 提示"保存成功"

### 5.6 随时唤起AI助手

1. 用户点击右下角"AI助手"按钮
2. 弹出对话窗口（带历史记录）
3. 用户输入问题或需求
4. AI分析当前页面context，给出回答
5. 支持多轮对话
6. 可最小化或关闭窗口

## 六、关键技术挑战与解决方案

### 6.1 Markdown内容的结构化解析

**挑战**：busi目录下的md文件需要解析成结构化数据

**解决方案**：

- 编写专门的parser，按照特定格式解析md文件
- 将解析后的数据存储为JSON，供前端使用
- 示例：将`data/busi/7.2`解析为`课程设计.json`格式

### 6.2 素材文件的动态加载

**挑战**：素材文件较多，需要按需加载

**解决方案**：

- 首次加载时只加载素材清单（metadata）
- 用户浏览素材库时，使用虚拟滚动+懒加载
- 缩略图使用压缩版本，预览时加载原图

### 6.3 课件的HTML渲染

**挑战**：课件需要支持PPT样式的翻页和动画

**解决方案**：

- 使用reveal.js库
- 每页课件是一个`<section>`
- 素材（图片、音频、视频）通过标签嵌入
- 支持键盘和鼠标控制翻页

### 6.4 AI调用的Context管理

**挑战**：AI需要了解当前页面内容和用户操作历史

**解决方案**：

- 每次调用AI时，动态构建context
- Context包含：
  - 当前模块名称
  - 当前编辑的内容
  - 相关的业务知识（如需要）
  - 用户操作历史（最近5条）
- 控制context长度，避免超出token限制

### 6.5 模块联动的状态同步

**挑战**：课程设计变化时，课件内容需要同步更新

**解决方案**：

- 使用Pinia的`watch`功能监听状态变化
- 变化时触发`syncToSlides()`函数
- 函数根据课程设计内容，更新对应的课件页面
- 提示用户："检测到课程设计变化，课件已自动更新"

# 🎯 教师备课Demo - 技术实现Skill

## 项目概述

构建一个基于Vue 3的Web应用，展示《秋天的怀念》课例的完整备课系统。核心亮点：系统化课程设计模版（框架+内容）+ 规格化素材体系 + AI智能辅助。

## 技术栈

- Vue 3 + TypeScript + Vite
- Element Plus（深色主题定制）
- Pinia（状态管理）
- Vue Router
- Axios
- markdown-it
- reveal.js（课件展示）

## 数据源说明

所有业务数据位于`data/busi/`目录，素材文件位于`data/resource/`目录。需要编写解析器将Markdown文件转换为结构化JSON数据。

## 核心功能模块（优先级排序）

### 1. 教学解读模块（只读展示）
