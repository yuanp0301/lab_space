### <font style="color:#8A8F8D;">初步研读</font>：目标提炼——确立教学坐标

**1. 单元定位与课标对标**

- **单元要求**（七年级上第二单元“至爱亲情”）：①感受和理解亲情；②继续学习朗读，把握感情基调；③了解不同抒情特点（直白/含蓄）；④学习在叙事中用细节表达情感。
- **课标衔接**：对应“欣赏文学作品”“品味语言”“有自己的情感体验”“获得人生启示”等要求。
- **本课核心定位**：本单元的开篇与定调之作，是落实 **“朗读训练”** 和 **“细节悟情”** 的核心范本，兼具强烈的情感熏陶和深刻的生命教育价值。

**2. 确立核心素养学习目标**

- **语言积累与建构**：掌握“瘫痪、憔悴、诀别”等关键词；通过朗读把握深沉内敛的感情基调。
- **<font style="background-color:#F1A2AB;">思维发展与提升</font>**<font style="background-color:#F1A2AB;">：梳理线索，通过细节分析人物形象（母亲与“我”），理解复杂交织的情感（怀念、悔恨、愧疚、领悟）。</font>
- **审美鉴赏与创造**：赏析文章含蓄深沉、质朴有力的语言，<font style="background-color:#F1A2AB;">学习细节描写、衬托、象征等手法。</font>
- **<font style="background-color:#F1A2AB;">文化传承与理解</font>**<font style="background-color:#F1A2AB;">：感悟母爱的无私与坚韧，理解“好好儿活”的生命哲学，增进对亲情的体悟。</font>

### <font style="color:#8A8F8D;">初步研读</font>：课程内核

**1. 素读批注，记录原初感动**

- **最刺痛处**：“她出去了，就再也没回来。” —— 平静叙述下的永别之恸。
- **最精妙处**：“母亲进来了，挡在窗前。” —— 一个“挡”字，是爱的本能，是绝望的防火墙。
- **最复杂处**：“对于‘跑’和‘踩’一类的字眼儿，她比我还敏感。” —— 爱的极致是战战兢兢。

**2. 追问核心，抓住文本灵魂**

- **核心矛盾是什么？** 儿子沉浸在 **自身残疾的痛苦** 中，母亲却独自承受着 **儿子痛苦 + 自身绝症 + 必须坚强** 的 **三重苦难**。这份信息差与情感错位，是全文张力的根源。
- **<font style="background-color:#F1A2AB;">教学支点在哪里？</font>**<font style="background-color:#F1A2AB;"> 在于那些 </font>**<font style="background-color:#F1A2AB;">“无声”的细节</font>**<font style="background-color:#F1A2AB;">：“悄悄地躲”、“偷偷地听”、“眼边红红”、“挡”、“忍住哭声”、“比我还敏感”。它们是母爱的密码，也是打开作者悔恨之门的钥匙。</font>
- **<font style="background-color:#F1A2AB;">终点指向何方？</font>**<font style="background-color:#F1A2AB;"> 从 </font>**<font style="background-color:#F1A2AB;">“秋天的怀念”</font>**<font style="background-color:#F1A2AB;"> 到 </font>**<font style="background-color:#F1A2AB;">“菊花的领悟”</font>**<font style="background-color:#F1A2AB;">。理解“秋天”从 </font>**<font style="background-color:#F1A2AB;">时间背景</font>**<font style="background-color:#F1A2AB;"> 升华为 </font>**<font style="background-color:#F1A2AB;">生命境遇的象征</font>**<font style="background-color:#F1A2AB;">；“怀念”从 </font>**<font style="background-color:#F1A2AB;">情感追忆</font>**<font style="background-color:#F1A2AB;"> 升华为 </font>**<font style="background-color:#F1A2AB;">生命信念的继承</font>**<font style="background-color:#F1A2AB;">。</font>

### <font style="color:#8A8F8D;">扩充参考</font>：资源要点整合与教学转化策略

本部将各类资源中的核心教学要点，转化为可直接应用于课堂的具体策略与支点，为教学设计提供专业、可操作的方案。

#### **维度一：整体教学设计——建构课堂逻辑与节奏**

| **教学要点（资源核心提炼）**                                    | **教学支点与策略（课堂实施路径）**                                                                                                                                                                                                                                                                                                                                          |
| :-------------------------------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **1. 双线并行**：叙事明线（三次看花）与情感暗线（“我”的成长）。 | **策略建议：可视化线索梳理**<br/>设计“双线追踪”学习单，引导学生在阅读中同步填写。一列梳理“看花”事件的时间、提议者与结果；另一列对应分析“我”的情感状态与关键表现。此工具旨在将内隐的情感变化外显，帮助学生**具象化理解情节推进与心理成长的共生关系**。                                                                                                                       |
| **2. 情感节奏**：文本情感张弛有度，形成独特的叙述韵律。         | **策略建议：情感变化直观化**<br/>引导学生合作绘制全文“情感心电图”**。以情节发展为横轴，情感强度为纵轴，共同标记关键段落的情感波峰（如暴怒、喜出望外）与波谷（沉寂、诀别），并标注文本依据。此活动旨在训练学生**整体把握文本情感基调与内在节奏的能力\*\*。                                                                                                                   |
| **3. 文眼聚焦**：“好好儿活”是统摄全篇的精神内核。               | **策略建议：阶梯式主问题驱动**<br/>围绕“好好儿活”设计环环相扣的核心问题链： <br/>1. **感知层**：母亲在何种情境下说出这句话？她自身的处境如何？ <br/>2. **理解层**：当时的“我”为何无法领会其深意？障碍何在？ <br/>3. **内化层**：文章结尾，“我”对“好好儿活”的领悟与母亲的原初期望有何继承与发展？ 通过追问，引导学生完成对文眼从**表层接收到深度理解与价值认同**的思维进阶。 |

#### **维度二：文本解读——深入矛盾与人物内核**

| **教学要点（资源核心提炼）**                                                  | **教学支点与策略（课堂实施路径）**                                                                                                                                                                                                                                    |
| :---------------------------------------------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **1. 核心矛盾**：儿子的显性痛苦与母亲的隐性痛苦构成巨大张力。                 | **策略建议：认知冲突情境创设**<br/>抛出深度思辨问题：**“文中，究竟谁承受着更沉重的苦难？”** 组织学生进行基于文本的证据性辩论。此活动旨在引导学生超越表象，通过对比分析，**深刻体认母亲所承载的“三重苦难”及其蕴含的爱的强度**。                                        |
| **2. 人物形象**：母亲形象是隐忍、细心、无私、坚韧、睿智等多维特质的有机融合。 | **策略建议：证据链人物分析法**<br/>开展“细节为证，为母亲画像”活动。要求学生不以概括性形容词先行，而是从文中筛选3-5处最富表现力的细节（动作、神态、语言），并阐释每一处细节揭示了人物何种特质。最终师生共同整合，**完成一个由文本证据支撑的、立体的母亲形象建构**。    |
| **3. 标题深意**：“秋天”与“怀念”均具有表层与深层双重意蕴。                     | **策略建议：标题比较与重构**<br/>在课堂收束阶段，引导学生进行**标题的替换与比较**（如改为《春天的怀念》或《忆母亲》）。通过对比分析，结合结尾“菊花”意象与生命感悟，引导学生自主阐释“秋天”作为**生命境遇象征**（凋零与成熟并存）以及“怀念”作为**精神传承**的深层内涵。 |

#### **维度三：语言品析——落实细节品味与手法领悟**

| **教学要点（资源核心提炼）**                                        | **教学支点与策略（课堂实施路径）**                                                                                                                                                                                                                                                                                                                                            |
| :------------------------------------------------------------------ | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **1. 细节描写**：精准的动词、叠词、副词是情感的微观载体。           | **策略建议：对比删改品析**<br/>针对关键语句（如“悄悄地躲”、“再也沒回来”），采用“原文—删改版”对比朗读与品析。引导学生聚焦被删改的词语，讨论其在刻画人物心理、渲染情感氛围上的不可替代性，从而**习得通过关键字词透视文本情感的方法**。                                                                                                                                          |
| **2. 象征手法**：菊花的多元色彩象征母爱的不同维度与生命的应然姿态。 | **策略建议：意象解读三级跳**<br/>对结尾菊花描写，设计渐进式解读阶梯： <br/>1. **描述感知**：不同颜色的菊花分别给你怎样的直观感受？ <br/>2. **关联迁移**：这种感受，让你联想到文中母亲的哪些品质或时刻？ <br/>3. **升华主旨**：作者浓墨重彩地描写“泼泼洒洒”的菊花，其意图仅在于写景吗？它象征着怎样的生命态度？ 此流程旨在帮助学生**自然生成对象征意义的理解，避免机械套用**。 |
| **3. 含蓄风格**：克制叙述与艺术留白强化了情感冲击力。               | **策略建议：留白处深度叩问**<br/>聚焦母亲未说完的遗言，设计探究问题：**“作者为何在此处使用省略号而非补全语句？如果补全，表达效果有何损失？”** 通过讨论，引导学生领悟**含蓄与留白在表达深沉复杂情感时，所具有的“此时无声胜有声”的艺术效果**。                                                                                                                                  |

#### **维度四：朗读教学——以声入情，化言为悟**

| **教学要点（资源核心提炼）**                                  | **教学支点与策略（课堂实施路径）**                                                                                                                                                                                                                            |
| :------------------------------------------------------------ | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **1. 把握基调**：全篇情感基调深沉内敛而富于变化。             | **策略建议：范读引领与感知标注**<br/>播放优质范读音频，要求学生在聆听时同步进行“情感感知标记”（如在沉重处画波浪线，在舒缓处画直线，在停顿处长记号）。听后分享标记意图，**在声音的直观浸润中初步把握文本的情感脉络**。                                         |
| **2. 分角色体悟**：通过声音演绎区别人物性格与心境。           | **策略建议：角色化朗读设计**<br/>选取典型对话段落（如第1、3段），指导学生进行 **“声音造型”** 。先分析人物特定情境下的心理状态，再共同设计其台词应有的语气、语调、语速、重音，并通过演读加以呈现和评议。旨在**通过声音的外化，促进对人物内在世界的内化理解**。 |
| **3. 朗读内化**：将个人理解与情感体验通过朗诵进行创造性输出。 | **策略建议：个性化深情朗诵展示**<br/>在深度学习后，设置“我的文中金句”朗诵环节。每位学生精选一句最有感触的语句，精心打磨朗读技巧后，面向全班诵读并简要陈述选择理由。此活动是**对文本的回归、对理解的表达，也是对情感的升华**。                                 |

#### **维度五：资源拓展——实现迁移与深度建构**

| **教学要点（资源核心提炼）**                            | **教学支点与策略（课堂实施路径）**                                                                                                                                                                                                                                                    |
| :------------------------------------------------------ | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **1. 知人论世**：史铁生的生平是理解其作品的精神底色。   | **策略建议：背景资料介入**<br/>采用“嵌入式背景介绍”，将作者生平资料分解为若干片段，在學生理解遭遇障碍时精准投送。例如，在分析“我”的暴怒时，插入其瘫痪前作为运动健将的资料，**制造命运的巨大反差，深化共情**；在探讨生命感悟时，链接《我与地坛》相关哲思段落，**拓展文本的哲学维度**。 |
| **2. 群文阅读**：通过群文比读，深化对母爱多样性的认识。 | **策略：比较阅读任务**<br/>将《合欢树》（节选）作为课后拓展材料，设计精炼的**比较阅读思考题**：“两篇文章中的母亲，在关爱儿子的具体方式上，表现出怎样不同的特点？”引导学生辨析《秋》的隐忍克制与《合》的执着坚韧，从而**建构对母爱表现形式多元化的认知**。                             |
| **3. 写作迁移**：借鉴文本细节抒情的方法进行微写作。     | **策略：微格写作训练**<br/>布置“捕捉亲情微光”情景写作任务。<br/>要求：模仿课文“让细节说话”的手法，描写一个与亲人相处的瞬间，**仅通过1-2个细微的动作、神态或语言描写来传递情感，避免直接抒情**。提供评价量表，强调细节的真实性与表现力。                                               |

### <font style="color:#8A8F8D;">学情分析</font>：学情分析与对策预设

| **维度**       | **学生可能的障碍**                                                                                                                   | **教师的“搭桥”策略（具体教学行为）**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| :------------- | :----------------------------------------------------------------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **认知与经验** | 1. 难以想象“瘫痪”对运动青年的毁灭性打击。 <br/>2. 对“肝癌晚期”的痛苦无概念。 <br/>3. 对“暴怒无常”的理解停留在“脾气坏”。              | **1. 背景反差渲染**：出示史铁生年轻时跨栏照片与文字描述，与其瘫痪后的状态形成 **视觉与心理的强对比**。 <br/>**2. 痛苦具体化**：解释“整宿整宿翻来覆去”，用 **“从深夜到黎明，每分钟都在忍受”** 来量化母亲的煎熬。 <br/>**3. 情绪溯源**：提问：“如果你最引以为傲的能力一夜之间永远失去，你会如何？” **链接次级挫折体验**，理解暴怒是绝望的外衣。                                                                                                                                                                                                                                                                                |
| **情感与共情** | 1. 易将母爱简单理解为“对我好”。 <br/>2. 难以体会作者 **“子欲养而亲不待”** 的永恒悔恨。 <br/>3. 对平静叙述下的情感风暴不敏感。        | **<font style="background-color:#F1A2AB;">1. 矛盾体验法</font>**<font style="background-color:#F1A2AB;">：设问：“母亲自己痛不欲生，却要对儿子说‘好好儿活’，她难不难？为什么能做到？”引导学生感受爱的 </font>**<font style="background-color:#F1A2AB;">“反本能”的坚韧</font>**<font style="background-color:#F1A2AB;">。 </font><br/>**2. 副词放大镜**：重点品析“一直”、“再也”。通过删词对比（如“不知道” vs “一直不知道”）， **放大悔恨的重量**。 <br/>**3. 留白处叩问**：针对母亲未说完的遗言，提问：“省略号里是什么？为什么作者不写出来？”体会 **“无言”胜“有言”** 的震撼。                                                  |
| **思维与方法** | 1. 阅读停留在情节概括和主题标签化（如“母爱伟大”）。 <br/>2. 不会主动抓取和深度分析细节。 <br/>3. 对象征的理解机械（如“菊花=坚强”）。 | **<font style="background-color:#F1A2AB;">1. 提供“分析支架”</font>**<font style="background-color:#F1A2AB;">：在小组探究时，给出任务单，引导从 </font>**<font style="background-color:#F1A2AB;">“找出细节” → “分析怎么写（词、句）” → “体会为何这么写（情感、人物）”</font>**<font style="background-color:#F1A2AB;"> 层层深入。</font> <br/>**2. 示范“细读”**：教师以第一段为例，示范如何从一个“扑”字，分析出母亲的惊慌、心痛与决绝。 <br/>**3. 阶梯式解读象征**：解读菊花时，三步走：**①描述客观形态**（颜色、姿态）→ **②链接人物品质**（让你想到母亲的什么？）→ **③升华主题内涵**（这仅仅是写花吗？它代表了什么期望？）。 |
